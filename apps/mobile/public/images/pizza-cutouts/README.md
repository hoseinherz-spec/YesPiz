# Transparent pizza cutouts

Created with the built-in imagegen tool from the corresponding original `../pizza-{name}.png` photographs, which are preserved. WebP conversion preserves alpha transparency.

Assets: margherita.webp, pepperoni.webp, salami.webp, bbq-chicken.webp, quattro-formaggi.webp, diavola.webp, tonno.webp, vegetariana.webp, funghi.webp, yespiz-special.webp.

Each image used this prompt, substituting its name:

Use case: background-extraction. Edit target: {name} pizza photograph. Remove ALL background, tabletop, plate, board, and cast shadow outside the food. Deliver a genuinely transparent RGBA PNG with alpha zero outside the pizza, NOT black/white/checkerboard simulated transparency. Preserve the pizza's toppings, shape, charred crust, texture, lighting and photographic appearance. Entire pizza isolated centered with small transparent margin, complete crust visible (extend cropped crust only where necessary). No text or additional objects.
