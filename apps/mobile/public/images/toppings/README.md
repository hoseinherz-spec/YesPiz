# Ingredient photography atlas

`ingredient-atlas.png` was generated with the built-in image_gen tool, then copied into this project. ToppingStudio renders individual cells using CSS background positions; row order is defined by ingredientAtlasNames in ToppingStudio.tsx.

Prompt: Create one production photographic ingredient sprite atlas for a pizza topping selector. Precisely six columns and six rows, equal cells, no gutters, text, labels or borders. Each cell contains a centered realistic overhead food ingredient pile with consistent studio food photography lighting. Row order: mozzarella, mushrooms, parsley, garlic, peppers, red onion; olives, pepperoni, chicken, basil, jalapeño, cherry tomatoes; San Marzano tomato, fior di latte, olive oil, tomato, chili honey, Italian salami; oregano, BBQ sauce, gorgonzola, parmesan, fontina, spicy salami; chili flakes, tuna, capers, zucchini, eggplant, burrata; prosciutto, arugula, truffle, dough, mozzarella, mixed herbs. Keep every ingredient within its cell with identical generous margins; small bowls only for sauces.

`pizza-base.png` was also generated with built-in image_gen. Prompt: A single perfectly circular baked pizza base viewed directly overhead, isolated on a genuinely transparent background. Golden thin Italian pizza dough with a puffy lightly charred crust and an even thin layer of red tomato sauce only inside, no cheese, herbs, vegetables, meat, plate or text. Photorealistic studio food photography, whole pizza centered with transparent margins, for separately overlaid toppings.

`pizza-neutral-base.png` is the final neutral customization base, generated with built-in image_gen by editing the sauce base. Prompt: Keep the exact top-down round crust, size, framing, realism and transparent background. Remove the tomato sauce and replace it with plain lightly baked pale golden dough. No sauce, cheese or toppings. Use separate layers to support tomato, BBQ or white-cheese recipes. The original finished pizza photograph remains the default until toppings change.

## Individual topping pieces
`ingredient-pieces.png` is a transparent 6×6 atlas generated with the built-in imagegen tool on 2026-09-26. It follows the same ingredient order as `ingredient-atlas.png`, but uses one photographed cooked piece per cell for natural scattering on the original pizza. No dish or badge is composited onto the pizza. Added toppings use stable ingredient-specific positions, rotations and sizes inside the crust; landing starts at the drop position and respects reduced motion. Removing a default ingredient changes the recipe, but cannot erase pixels baked into the original photograph.
