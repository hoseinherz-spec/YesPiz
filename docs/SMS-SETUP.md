# راه‌اندازی پیامک

کد ارسال و تأیید OTP به Twilio Verify وصل است. برای فعال‌سازی، بعداً اطلاعات حساب خود را در `apps/api/.env` قرار دهید:

```dotenv
TWILIO_ACCOUNT_SID=AC...
TWILIO_AUTH_TOKEN=...
TWILIO_VERIFY_SERVICE_SID=
OTP_DEV_BYPASS=false
```

از ریشهٔ پروژه اجرا کنید:

```sh
npm run sms:setup
```

این فرمان حساب را بررسی می‌کند، سرویس `Yespiz Sandbox` را پیدا می‌کند یا می‌سازد، شناسهٔ سرویس را در همان `.env` ذخیره می‌کند و ورود آزمایشی با `000000` را غیرفعال می‌کند. اگر `TWILIO_VERIFY_SERVICE_SID` را قبلاً گذاشته باشید، همان سرویس بررسی می‌شود. سپس API را دوباره راه‌اندازی کنید. فرمان راه‌اندازی هیچ پیامکی ارسال نمی‌کند و شماره‌ای نمی‌خرد. کلیدها در خروجی چاپ نمی‌شوند.

اگر ترجیح می‌دهید تنظیمات Trial جدا باشد، `.env.twilio-sandbox.example` را به `.env.twilio-sandbox` کپی کنید؛ مقادیر آن بر `.env` اولویت دارند. این فایل در Git نادیده گرفته می‌شود.

## رفتار پیاده‌سازی‌شده

- شماره باید قالب بین‌المللی مثل `+4915123456789` داشته باشد.
- کانال این فلو فقط SMS است و کد دقیقاً شش رقم دارد.
- ارسال مجدد با فاصلهٔ زمانی کنترل می‌شود؛ محدودیت سرویس به خطای 429 تبدیل می‌شود.
- خطای ارسال، چالش محلی همان درخواست را حذف می‌کند؛ موفقیت جعلی گزارش نمی‌شود.
- کد منقضی، اشتباه یا بیش از حد امتحان‌شده پذیرفته نمی‌شود.
- سرور اعتبار کد را از Verify می‌گیرد؛ OTP و جزئیات محرمانهٔ سرویس در پاسخ ظاهر نمی‌شوند.
- حالت production همواره bypass توسعه را نادیده می‌گیرد.

## تست نهایی بعد از وارد کردن کلید

در اپ با شمارهٔ مورد تأیید حساب Trial درخواست کد کنید، کد دریافتی را وارد کنید و یک بار نیز کد اشتباه و ارسال مجدد زودهنگام را امتحان کنید. تست خودکار adapter بدون ارسال پیامک اجرا می‌شود:

```sh
npm run test --workspace=api -- --runInBand --watchman=false sms.spec
```

به درخواست مالک پروژه، دریافت کلید و ارسال واقعی به بعد موکول شده است؛ هیچ حساب یا شمارهٔ تأییدنشده‌ای به‌جای آن ساخته نشده و دریافت واقعی SMS هنوز تأیید نشده است.

Twilio Verify با «Test Credentials» عمومی کار نمی‌کند؛ برای ارسال آزمایشی از حساب Trial و گیرندهٔ تأییدشده استفاده کنید. محدودیت جغرافیایی و فعال بودن کشور مقصد را در حساب خود تنظیم کنید. [مستندات رسمی Verify](https://www.twilio.com/docs/verify/quickstarts) و [توضیح تفاوت Test Credentials](https://www.twilio.com/docs/iam/test-credentials).
